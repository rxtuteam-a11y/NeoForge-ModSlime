        Cài đặt

        Không cần tài khoản. Ai mở trang cũng xem được log; chỉ người có GitHub token của chủ server mới bật/tắt, gõ lệnh và sao lưu được. Token chỉ lưu trên trình duyệt này.
        1. Mở github.com/settings/personal-access-tokens/new
        2. Repository access → Only select repositories → chọn repo server.
        3. Permissions → Actions: Read and write, Contents: Read-only. Muốn cài Playit/Drive ngay trên trang này thì thêm Secrets và Variables: Read and write.
        4. Generate, chép token dán vào đây.
        🔧 Cấu hình server trên GitHub (Playit, địa chỉ game, Google Drive)
        Đang đọc cấu hình…
        Secret được mã hoá ngay trong trình duyệt (libsodium) rồi mới gửi lên GitHub; không ai đọc lại được, kể cả trang này.
        📲 Cho thiết bị khác điều khiển server (không cần cài lại)
        Tạo link (hoặc mã QR) chứa quyền điều khiển. Máy khác mở link là bật/tắt, gõ lệnh được ngay. Ai có link đều điều khiển được — chỉ gửi cho người tin tưởng.
        Nên tạo token riêng cho bạn bè chỉ với quyền Actions: Read and write + Contents: Read-only (không có Secrets/Variables) và đặt ngày hết hạn. Muốn thu hồi thì xoá token đó trên GitHub.
        Trình duyệt chặn trang https gọi tới địa chỉ http. Nếu không kết nối được, mở thẳng địa chỉ Web Panel (vd. http://localhost:8080) — trang này có sẵn ở đó.
