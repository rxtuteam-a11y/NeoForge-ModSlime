    Nhóm / Tính Năng Câu Lệnh / Địa Chỉ Công Dụng Chi Tiết Thao Tác Nhanh
    Chunky Pre-gen (Tạo Map Trước) chunky radius 3000 Đặt bán kính tạo trước địa hình 3000 blocks quanh tâm (giảm 90% lag khi khám phá map mới).

    Chunky Pause / Continue chunky pause Tạm dừng tạo chunk khi đông người chơi (dùng chunky continue để chạy tiếp).
    Chunky Progress (Tiến độ) chunky progress Kiểm tra phần trăm (%) tiến độ tạo map và tốc độ CPS hiện tại.
    Spark TPS & RAM spark tps Xem chỉ số TPS (chuẩn 20.0), MSPT và dung lượng CPU/RAM server đang tiêu thụ.
    Spark Profiler (Tìm nguyên nhân lag) spark profiler start --timeout 60 Đo hiệu năng server trong 60 giây và xuất link báo cáo chi tiết mod/entity nào gây lag.
    Spark Health Report spark healthreport Kiểm tra tổng thể sức khỏe máy chủ, ổ cứng, RAM và các chỉ số JVM GC.
