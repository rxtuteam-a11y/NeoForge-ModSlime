📖 Hướng Dẫn Mở Server Bằng Radmin VPN Chi Tiết Từng Bước (Không Bỏ Bước)

Làm đúng lần lượt từng bước dưới đây để Chủ Máy mở server mượt mà và Bạn Bè có thể vừa điều khiển Bật/Tắt Server từ xa, vừa vào chơi Minecraft 266 Mods qua mạng ảo miễn phí Radmin VPN.

🛠️ Phần 1: Chuẩn bị cho Chủ Máy (Host) lần đầu tiên ▼
1.1
Tải và cài đặt Radmin VPN miễn phí: Truy cập https://www.radmin-vpn.com/ → bấm Free Download → chạy file cài đặt và bấm Next đến khi hoàn tất.
1.2
Tạo mạng Radmin VPN riêng cho nhóm: Mở phần mềm Radmin VPN → bấm nút nguồn Bật (Power) nếu đang tắt → trên thanh menu chọn Network (Mạng) → chọn Create network (Tạo mạng mới) → đặt Tên mạng (VD: ModSlime-Team) và Mật khẩu (VD: 12345678) → bấm Create.
1.3
Xem địa chỉ IPv4 Radmin VPN của bạn: Ngay dòng đầu tiên bên cạnh tên máy tính trong cửa sổ Radmin VPN sẽ hiện địa chỉ dạng 26.x.x.x. Đây là IP mạng ảo để bạn bè kết nối cả Web Panel lẫn Minecraft.
1.4
Mở cổng Windows Firewall (Cực kỳ quan trọng — làm 1 lần duy nhất): Mở thư mục c:\Users\phankhang\Desktop\NeoForge-ModSlime\web-panel\ → chuột phải vào file Mo-Cong-Firewall-Radmin.bat → chọn Run as administrator (Chạy với quyền Quản trị viên). Script sẽ tự động mở cổng TCP/UDP 25565 (Minecraft) và 8080 (Web Panel) để bạn bè kết nối không bị Windows chặn.
1.5
Khởi chạy Web Control Panel: Nhấp đúp mở file web-panel\Start-Web-Panel.bat. Màn hình đen nhỏ sẽ chạy nền và tự mở trình duyệt tại http://localhost:8080 (đồng thời mở sẵn cho bạn bè truy cập tại http://26.x.x.x:8080).
👥 Phần 2: Cách Bạn Bè cùng điều khiển Bật / Tắt Server từ xa qua Radmin VPN ▼
2.1
Cài đặt Radmin VPN: Bạn bè tải và cài Radmin VPN từ radmin-vpn.com (hoàn toàn miễn phí, không cần tạo tài khoản).
2.2
Tham gia mạng của Chủ Máy: Mở Radmin VPN → chọn menu Network (Mạng) → chọn Join network (Tham gia mạng có sẵn) → nhập đúng Tên mạng và Mật khẩu mạng do Chủ Máy gửi → bấm Join. Chờ thấy tên Chủ Máy hiện dấu chấm xanh lá là đã thông mạng.
2.3
Mở trang Web Điều Khiển Server: Có 2 cách đều dùng được:
  • Cách nhanh nhất (Khuyên dùng): Mở Chrome/Edge và gõ thẳng link http://26.x.x.x:8080 vào thanh địa chỉ.
  • Cách mở từ file tải về / Website chính thức: Mở file ModSlime-Server-Control.html (hoặc trang web GitHub Pages), ở ô Địa chỉ Web Panel nhập http://26.x.x.x:8080.
2.4
Đăng nhập bằng Tài khoản & Mật khẩu chung: Nhập tài khoản modslime và mật khẩu modslime2026 (hoặc mật khẩu mới nếu Chủ Máy đã đổi) → bấm 🔓 ĐĂNG NHẬP BẢNG ĐIỀU KHIỂN.
2.5
Bật / Tắt Server thoải mái: Bấm ▶ BẬT SERVER, đợi khoảng 30–60 giây cho đến khi trạng thái chuyển sang 🟢 ĐANG MỞ (Console hiện dòng Done (...s)!) là cả nhóm vào chiến! Khi chơi xong nhớ bấm ⏹ TẮT & LƯU SERVER để lưu toàn bộ tiến trình lên GitHub.

🧯 Phần 5: Xử lý lỗi thường gặp & Mẹo chống lag bằng Chunky ▼
5.1
Lỗi: Bạn bè không vào được Web Panel (:8080) hoặc Minecraft báo Connection timed out / getsockopt:
  • Kiểm tra cả 2 máy đã bật Radmin VPN và đang nằm chung 1 phòng (đèn báo xanh lá, không bị gạch đỏ).
  • Trên máy Chủ, chuột phải file web-panel\Mo-Cong-Firewall-Radmin.bat → chọn Run as administrator để mở thông cổng 25565 và 8080.
  • Nếu mạng công ty/ký túc xá hoặc Windows Defender vẫn chặn, tạm tắt Windows Defender Firewall cho mạng Private/Public hoặc cho phép ngoại lệ java.exe & python.exe.
  • Kiểm tra trong Console đã hiện dòng Done (...s)! For help, type "help" chưa.
5.2
Lỗi: Mở link GitHub Pages (https://...) không kết nối được Web Panel Radmin (http://26.x.x.x:8080): Do quy định bảo mật Mixed Content của trình duyệt (chặn trang https:// gọi API sang http://). Cách xử lý: Bạn bè chỉ cần gõ thẳng http://26.x.x.x:8080 vào thanh địa chỉ trình duyệt, hoặc mở trực tiếp file ModSlime-Server-Control.html trên máy tính!
5.3
Chống lag / tụt TPS khi khám phá map mới bằng Chunky:
  • Khi chưa có người chơi online, bấm lần lượt các nút nhanh ở khung Console: chunky center 0 -550 → chunky radius 2000 → chunky start để máy chủ dựng sẵn map.
  • Quan trọng: Khi bạn bè chuẩn bị vào chơi, nhớ bấm chunky pause để dừng tạo map, giúp Server giữ 20.0 TPS siêu mượt!
  • Kiểm tra độ mượt bất kỳ lúc nào bằng nút spark tps.
5.4
Lưu ý khi tạo World mới tinh lần đầu: Sau khi Console hiện Done, nên đợi ít nhất 45 giây trước khi tắt server để mod Tensura dựng xong dữ liệu mê cung (Labyrinth).
